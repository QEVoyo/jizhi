# 2026-08-01 开发日志

## 认证降级 — Supabase 不可用时的免登录模式

Supabase 项目暂停导致所有依赖认证的 API 500/401。题库是本地 JSON，无需登录即可访问，移除了以下端点的认证依赖：

| 端点 | 改动 |
|---|---|
| `GET /subject-plan/syllabi` | 去掉 `Depends(get_current_user)` + `verify_user_match`，user_id 可选 |
| `GET /subject-plan/syllabi/{id}` | 同上 |
| `GET /subject-plan/questions/by-ids` | 去掉认证，user_id 可选 |
| `POST /subject-plan/code/submit` | 去掉认证 + 不再依赖 plan_id，直接用 syllabus_id 查本地题库 |
| `POST /subject-plan/code/run` | 🆕 新增：运行代码（自定义输入），无认证 |

**原则**：读题库 → 免登录。写操作 → 需要 Supabase 恢复后才有。

### 前端适配

- `SyllabusHub.vue`：`authStore.user?.id || ''` 兜底，无用户时也能加载考纲列表
- `SyllabusDetail.vue`：同上
- `SubjectPractice.vue`：`plan_id` 可选，无计划也能进入做题页（题库自由练习模式）

## 微信扫码登录（网页版）

### 方案选型

因微信开放平台「网站应用」需企业资质（300 元/年），采用**公众号测试号 OAuth + 扫码轮询**方案：

- 公众号测试号：个人免费、无需认证、API 完整
- 授权方式：`snsapi_userinfo`（可获取 openid + 昵称 + 头像）
- 交互方式：网页展示二维码 → 手机微信扫码 → 微信浏览器授权 → 网页轮询拿到 session

### 登录流程

```
网页点击「微信扫码登录」
  → 后端生成二维码（qrcode）+ poll_token
  → 前端展示二维码 + 开始轮询
  → 用户微信扫码 → 公众号授权页 → 确认
  → 微信浏览器回调后端 /auth/wechat/callback?code=xxx&state=xxx
  → 后端换 access_token/openid → 查用户是否已绑定
    → 已绑定：签发 JWT → 前端轮询拿到 → 登录成功
    → 未绑定：返回 bound:false → 前端提示「请先登录后在个人中心绑定」
```

### 账号绑定

不在扫码时自动创建用户，必须先有账号才能绑定微信：

- 个人中心新增「🔗 微信绑定」卡片 → 扫码 → openid 写入 profiles
- 后端区分 login / bind 两种模式（state 中记录 mode）

### 自签 JWT

微信登录不依赖 Supabase Auth，自签 JWT（PyJWT HS256）。

- 中间件（`auth_middleware.py`）升级为双重认证：优先验证自签 JWT → 失败再走 Supabase
- JWT 有效期 30 天

### 后端新增文件及端点

| 端点 | 说明 |
|---|---|
| `GET /auth/wechat/qrcode` | 生成登录二维码 + poll_token |
| `GET /auth/wechat/bind-qrcode` | 🔒 已登录用户获取绑定二维码 |
| `GET /auth/wechat/callback` | OAuth 回调（手机微信浏览器访问） |
| `GET /auth/wechat/poll/{token}` | 轮询扫码结果 |
| `POST /auth/wx-login` | 小程序登录（`jscode2session`→JWT）|
