# 2026-07-24 开发日志

## 架构重构：考纲体系

**从单考纲计划列表 → 多考纲卡片体系**

- 新建 `backend/data/syllabi.json`，15 个大学生高频考试考纲（CET-4/6、考研、雅思、托福、计算机二级、教资、CPA 等）
- 一个考纲 = 一个计划，不再有多计划列表
- 路由重构：
  - `/subject-plan` → SyllabusHub.vue（考纲列表）
  - `/subject-plan/:syllabusId` → SyllabusDetail.vue（考纲详情 Tab 总控台）
  - `/subject-plan/:syllabusId/practice` → SubjectPractice.vue（做题页）
  - 删除 `/subject-plan/bank`、`/subject-plan/diagnosis` 独立路由

## 本地题库

- 新建 `backend/local_question_bank.py`：启动时从 JSON 加载全部题目到内存
- 新建 `backend/data/cet4_questions.json`：302 题（原有 110 + AI 生成 192）
- 题库查询从 Supabase HTTP → Python 内存，零延迟
- 新增 API：`GET /subject-plan/questions/by-ids`（按 ID 批量取题）

## 考纲列表功能

- 搜索框：按名称/描述实时过滤
- 筛选胶囊：全部 / 已收藏 / 可用考纲，各带数量角标
- 收藏：心形按钮，localStorage 持久化
- 空态引导

## 考纲详情功能

- 题库 Tab 始终可见（不依赖计划是否生成）
- 无计划时：轻量横幅提示 + 诊断入口
- 题库完成度进度条（绿色渐变）
- 题目收藏（❤ localStorage）+ 收藏筛选
- 已做题标记（左侧绿边 + ✓）
- 题库筛选：维度 / 子分类 / 题型 / 搜索
- 每日任务 Tab（需先生成计划）
- 知识点掌握度 Tab
- 错题本 Tab
- 诊断 2 步流程（做题 → 设目标）内嵌在详情页

## UI 重设计

- 全套毛玻璃风格（backdrop-filter: blur + 半透明 + 深色底）
- 所有可交互元素有 hover 动效（位移/光晕/边框变色）
- 考纲图标改用缩写标（abbr）+ 颜色（color），不用 emoji
- 题目选项 hover 滑入效果 + 选中高亮
- 加载脉冲动画替代文字 loading

## Bug 修复

- **路由 404**：`/{plan_id}` 动态路由抢在 `/questions` 前面匹配，把 `questions` 当成 plan_id 返回 404。修复：`/questions` 移到 `/{plan_id}` 之前
- **做题页路由**：`route.params.id` → `route.query.plan_id`，适配新路由参数
- **题库不可见**：题库 Tab 从 `v-if="plan"` 内部移出，始终渲染
- **GBK 编码**：seed 脚本添加 UTF-8 stdout wrapper
