### 登录 & 账号绑定

**后端新增**：
- `POST /auth/wx-bind` — 小程序绑定已有网页账号（openid + 邮箱/用户名 + 密码 → 验证 → 写入 wechat_openid → 返回 JWT）
- `WxBindRequest` Pydantic 模型
- `wx-login` 改为不自动创建用户，未绑定返回 `need_bind: true`

**小程序新增**：
- 登录页两步流程：微信授权 → 未绑定展示绑定表单（邮箱/用户名 + 密码）
- `bindAccount()` 方法（stores/auth.js）
- 绑定后网页端和小程序端均可微信登录，共享同一账号体系

**环境配置**：`.env` 填入 `WECHAT_MP_SECRET`

### showLoading/hideLoading 配对修复

**问题**：`request.js` 遇到错误时调 `showToast`，微信里 showToast 会自动关掉 showLoading，然后 `auth.js` 的 catch 再调 `hideLoading` → 报配对错误。

**修复**：
- `auth.js`：login() 用 `silent: true` 不让 request 层弹 toast，改用 `finally` 确保 hideLoading 执行
- `request.js`：去掉无条件 hideLoading（避免非 loading 场景误报）

### API 路径全面修正

**问题**：小程序 API 路径全部写错，调的是不存在的端点（如 `/subject-plan/plan/cet4`、`/career/achievements/{uid}`、`/chat/sessions` 等）。

**修复** (`api/subjectPlan.js`、`api/career.js`)：

| 模块 | 错误路径 | 正确路径 |
|------|---------|---------|
| 考题详情 | `/subject-plan/plan/{id}` | `/subject-plan/syllabi/{id}` |
| 题库查询 | `/subject-plan/{id}/questions` | `/subject-plan/syllabi/{id}/questions` |
| 诊断开始 | `/subject-plan/{id}/diagnosis` | `/subject-plan/syllabi/{id}/diagnosis/start` |
| 诊断提交 | `/subject-plan/{id}/diagnosis` | `/subject-plan/syllabi/{id}/diagnosis/submit` |
| 答题提交 | `/subject-plan/{id}/submit` | `/subject-plan/plans/{plan_id}/submit` |
| 学程成就 | `/career/achievements/{uid}` | 从 `stats.achievements` 提取 |
| 学程任务 | `/career/tasks/{uid}` | `/career/task-progress/{uid}` |
| 会话管理 | `/chat/sessions` | 改为本地 storage（无后端端点） |
| getSyllabusDetail | 直接返回 `{syllabus, plan}` | 自动解包 `data.syllabus` |

### 题库免登修复

### 诊断流程

**小程序** (`pages/study/practice.vue`)：
- 支持诊断模式（`mode=diagnosis`）
- 诊断题批量加载 → 逐题作答 → 每题显示进度（N/M）
- 全部答完 → `POST /syllabi/{id}/diagnosis/submit` → 生成学习计划
- 正确率弹窗 → 返回详情页

**详情页** (`pages/study/detail.vue`)：
- `startDiagnosis()` 调用 `/diagnosis/start` → 存题到 storage → 跳转 practice 诊断模式

### 对话页布局重写

**问题**：
- 顶栏 `justify-content: space-between` 挤走 logo
- `.chat-logo` CSS 定义两次互相覆盖
- 空 emoji 占位残留
