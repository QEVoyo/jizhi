- canvas 2x 渲染华文行楷骨架，矢量渐变填充（无噪点）

- 浅色：底片 rgba(255,253,248,.96)→rgba(245,241,232,.98) + 暖墨字 #3a3225→#57482f→#221c14 + 暗金描边

### 技术坑记录
- **vite dev 字体加载坑**：`import '@fontsource/...'` 的 CSS 被当 JS 模块注入，`url(./files/...)` 相对路径不重写 → 浏览器按页面路径请求 `/files/*.woff2` 命中 SPA 回退（200 text/html）→ 字体 face status=error 静默回退系统字体。诊断：全角中文字形宽度相同，宽度对比发现不了，canvas 像素对比才实锤。修复：字体文件复制 `public/fonts/`，index.html 原生 `<link>` 加载（unicode-range 分片按需下载 ~120KB）
- npm 装 fontsource 包遇 vite/esbuild ERESOLVE，用 `--legacy-peer-deps` 绕过

### 遗留
- `public/fonts/` 下 liu-jian-mao-cao / zhi-mang-xing 两份字体文件留着备选（各 9.5MB 量级，仅按需加载）；不用可删
