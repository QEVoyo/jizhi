## 出题提示词排查：题目都偏向 Python（根因 4 条 + 修复）

- **现象**：资源库/小基生成题目，不管什么知识点都往 Python 偏
- **根因**（`routers/questions.py` `/questions/generate`）：
  1. `category` 默认值写死 `"Python"`
  2. 提示词无学科锚定，传「通用」时模型自由发挥、训练数据里 Python 最多
  3. 归一化规则示例全是 Python 味（「装饰器」「Python集合」）
  4. 出题角度池含「代码示例/性能分析」等编程术语，随机抽中就把题带成算法题
- **修复**：
  - 默认值 `"Python"` → `"通用"`
  - 新增**【学科自定·最高优先】**规则：学科通用/未指定时先按知识点判定所属学科（数学/英语/语文/物理…）并严格在该学科语境内出题；除非知识点本身是编程类，否则严禁 Python/代码/算法/时间复杂度等概念
  - 编程术语角度要求转译成该学科对应角度
  - 归一化示例换成中性示例（二次函数最值/三角函数/定语从句），长度放宽 2-12 字
  - 编程题 `starter_code` 模板仅限编程类知识点
- **实测**：「函数」→ 数学奇偶性/单调性题 ✅；「定语从句」→ 英语语法题（最高级修饰用 that）✅
