# 2026-07-26 开发日志

## 管理员系统

**从无到有搭建完整管理后台**

### 三级角色体系

- `super_admin` 超级管理员 — 全部权限 + 可设/撤管理员
- `admin` 管理员 — 管理用户和内容，不能管其他管理员
- `user` 普通用户 — 无管理后台权限
- profiles 表新增 `role` 字段（TEXT DEFAULT 'user'），兼容旧 `is_admin` 字段

### 管理后台页面

| 路由 | 文件 | 说明 |
|---|---|---|
| `/admin` | `AdminDashboard.vue` | 主面板：8 个统计卡片 + 快捷入口 |
| `/admin/users` | `AdminUsers.vue` | 用户管理：搜索/封禁/设管理员（仅超管可见）/详情弹窗 |
| `/admin/reports` | `AdminReports.vue` | 内容审核：举报/反馈/Q&A 三个 Tab |

| `/admin/questions` | `AdminQuestions.vue` | 题库管理：CRUD + 筛选 + 批量导入 JSON |
| `/admin/announcements` | `AdminAnnouncements.vue` | 公告管理：发布/编辑/下架 + 图片上传 + 预览 |
| `/admin/logs` | `AdminLogs.vue` | 操作日志：按类型筛选 |

### 登录页重设计

- 三栏 Tab：用户登录 / 🛡管理员登录 / 用户注册
- 管理员登录后自动检测 `is_admin`/`role`，非管理员提示"无管理员权限"并清除登录态
- 管理员登录成功直接跳转 `/admin`
- 普通用户登录跳转 `/home`

### API 端点（/admin 前缀）

- **仪表盘**：GET /admin/dashboard（用户数/做题数/待处理举报/计划数）
- **用户管理**：GET/PUT /admin/users + 状态/角色控制
- **内容审核**：GET/PUT /admin/reports + 反馈 + Q&A
- **题库**：GET/POST/PUT/DELETE /admin/questions + 批量导入
- **公告**：GET/POST/PUT/DELETE /admin/announcements + 公开查询
- **图片**：POST /admin/upload-image（Supabase Storage）
- **日志**：GET /admin/logs
- **系统**：GET /admin/settings
