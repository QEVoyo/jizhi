## 循环依赖导致 API 全挂

- **问题**：`request.js` ↔ `stores/auth.js` 互相 require，CommonJS 模块加载时 `useAuthStore` 为 undefined，所有 API 调用在发请求前崩溃
- **表现**：学习页「加载失败」，控制台无网络请求日志
- **修复**：`request.js` 直接从 `uni.getStorageSync('token')` 读 token，不再引用 authStore；401 处理改用直接清理 storage
- **文件**：`src/utils/request.js`

## 小程序 — AI 对话 SSE 流式输出

### 问题
`uni.request` 不支持分块传输，AI 回复需要等待完整响应后才一次性展示，体验极差（和网页版逐字输出差距大）

### 修复
- 用 `wx.request`（原生）替换 `uni.request`，启用 `enableChunked: true` + `onChunkReceived`
- UTF-8 ArrayBuffer 手动解码，逐字追加到消息气泡
- streaming 时显示闪烁光标 `|`
- 对话历史（最近 10 轮）作为上下文传给后端
- 首条消息后自动调 `/chat/title` 生成对话标题
- 页面卸载时 `requestTask.abort()` 取消请求

| 文件 | 改动 |

| `src/pages/index/index.vue` | 完全重写 — 410 行，SSE 流式聊天 |
| `src/utils/constants.js` | BASE_URL → `https://api.jizhi-learn.com` |
