### 胶囊倒计时（时间胶囊）设计定稿 —— 用户拍板，晚上开工

**概念**：把现有「倒计时」工具改版为**时间胶囊**——创建时写下留言并密封，到期日手动开启，密封期只能追加留言（带时间戳），不能看、不能删。

#### 数据模型（沿用 Supabase `countdowns.events` JSONB，无需新表）
```
{
  id, title, target_date, created_at,
  entries: [ { content, created_at }, ... ],   // 留言条目，每条带时间戳
  opened_at: null                              // 手动开启时刻（开启后写入）
}
状态派生：未到期 = 密封中；到期未开启 = 待开启；已开启 = opened_at 非空
```

#### 行为规则（全部用户拍板）
- **密封期（到期前）**：
  - 卡片显示：标题 + 实时倒计时（天:时:分:秒）+ 🔒 密封中徽章 + 创建时间 + 「已写 N 条」
  - 可点「＋ 添加留言」追加条目（每次带时间戳）；密封区占位「🔒 内容已密封，共 N 条留言，X月X日开启后可见」
  - 不可：查看内容 / 删除任何条目 / 删除整颗胶囊 / 改标题与日期
- **到期日**：通知中心发通知（复用 notifications 体系）「胶囊已到开启时间」；卡片变「待开启」橙色高亮
- **开启仪式（用户指定：手动开启）**：点「开启胶囊」按钮 → 写入 opened_at → 展开全部条目（按时间戳排列）+ 开启时间
- **开启后**：状态「已开启」；不可再追加留言；可删除整颗胶囊（清理用）

#### 默认约定（替用户定的，可再议）
- 留言单条限 500 字；胶囊上限 50 颗
- 密封 = UI 层不展示（数据明文在 JSONB；真加密忘掉即找不回，暂不做）

#### 动画要求（用户指定：必须精心设计）
- **生成胶囊动画**：方向——写下留言 → 封口仪式（壳闭合/封印盖下）→ 胶囊落入列表；具体实现晚上设计（备选：两瓣胶囊壳闭合 + 下落缓动 + 列表插入展开；或折纸折叠封口风）
- **打开胶囊动画**：方向——点「开启胶囊」→ 破封效果（封印裂开/光缝漏出）→ 壳展开 → 留言条目逐条浮现（时间戳）；可配粒子/光效，须与全站科幻毛玻璃风一致
- 动画期间禁用交互；尊重 prefers-reduced-motion 降级
