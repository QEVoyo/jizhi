## Bug 修复（代码审查后）

共修复 12 个缺陷，按严重程度排列：

### 🔴 严重（3 个）
1. **SubjectPractice 完形填空渲染错误** — `isSingleChoice` 包含 `cloze` 导致渲染为单选按钮而非下拉框。移除 `cloze` 后走正确的 v-else-if 分支。
2. **知识点掌握度不聚合** — 每次答题都 INSERT 新行，字段名也不匹配 DB schema。改为先查→聚合 UPDATE→首次 INSERT，使用 EWMA 算法平滑分数。
3. **可重复创建计划** — submit_diagnosis 不检查已有活跃计划。新增 `_get_user_plan` 检查，已存在则返回已有 plan_id。

### 🟠 重要（4 个）
4. **每日任务题目无去重** — 同日不同任务可能抽到相同题目。新逻辑排除已答题 ID + 已分配 ID。
5. **categoryLabel/typeLabel 硬编码** — 两个 Vue 文件各维护 ~50 行映射。创建 `utils/questionLabels.js` 共享工具，category 从 dimensions 动态构建。
6. **诊断分数范围硬编码 300-710** — CET 专用滑块不适配其他考试。syllabi.json 新增 max_score/pass_score，前后端全链动态读取。
7. **收藏仅存 localStorage** — 需服务端持久化（待后续）

### 🟡 次要（5 个）
8. **题库收藏筛选分页 total 错误** — 收藏模式改为全量拉取→客户端过滤→客户端分页
9. **跨考纲错题 N+1 查询** — 改为 Supabase `in.()` 批量查 plan→syllabus 映射
10. **v-html XSS 风险** — fillStemHtml 添加 HTML 标签剥离
11. **前端无删除计划入口** — plan-bar 新增「删除计划」按钮（确认弹窗）
12. **analysis 题型缺失** — 加入 AI_JUDGE_TYPES 和 type_labels 映射
