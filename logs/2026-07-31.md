### 与 Web 版的差异处理

| 特性 | Web | 小程序 | 处理 |
|---|---|---|---|
| 编程题 | ✅ 代码沙箱 9 语言 | ❌ | `SKIP_QUESTION_TYPES: ['programming']` |
| 算法考纲 | ✅ algorithm-ds, acm-icpc | ❌ | `SKIP_SYLLABUS_IDS` 过滤 |
| 毛玻璃 | ✅ backdrop-filter | ❌ | 降级为 `rgba(255,255,255,0.06)` 半透明 |
| OCR 拍照 | ❌ | ✅ | 微信原生 OCR + 后端降级上传 |
| 管理后台 | ✅ 6 页面 | ❌ | 小程序不需要 |

### 适配改造

- **请求层**：`utils/request.js` — 从 axios 改为 `uni.request`，保留 401 自动登出 + 重试 + toast 提示
- **登录**：`uni.login` 获取微信 code → 后端 `/auth/wx-login` 换 token
- **存储**：token/user 用 `uni.setStorageSync` 持久化，收藏用 localStorage 降级
- **安全区**：所有页面底部 + Tab 栏适配 `env(safe-area-inset-bottom)`
- **自定义 TabBar**：`CustomTabBar.vue`，emoji 图标 + 深色背景 + active 高亮

### 编译配置

- `project.config.json`：`urlCheck: false` + `libVersion: 2.32.3`（兼容旧版基础库）
- `manifest.json`：微信 appid + 权限声明（用户位置用于打卡）
- `BASE_URL`：`http://localhost:8000`（开发环境，上线后改生产域名）
