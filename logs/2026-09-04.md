### 码设计（`utils/appearanceCode.js`，纯前端零后端）
- **核心创意：码本身就是四轴色值，可读、可手改**
  - `JZ1-0d1220-16233c-409eff-paper-CK2F8` —— 前缀 + 背景/组件/主题三个 hex 直排 + 字体档 + 5 位校验；好友能「读出」配色，甚至手改某个 hex 微调再回传
  - **官方套装超短别名**：四轴恰为 6 套方案之一 → `JZ1-space`（像游戏种子），展示注明「深空蓝套装」
  - custom 字体档跟三档字色 hex：`JZ1-...-custom-e9f4f6-a8c2c8-779298-XXXXX`
- **5 位校验码**：djb2 哈希 → 32 字符表（剔 0/O/1/I/L）5 位 32 进制；抄错/缺字符弹具体错误而不是静默套错色
- **宽容解码**：大小写、`·._-` 与换行分隔符、随手带的 `#` 号均可；错误信息逐类（缺前缀/段数/非法色值/未知字体档/未知套装/校验失败）
- 零损耗：自由 RGB 取色不量化

## 视频库方案定稿（晚间讨论,用户逐步拍板）

### 用户定调（多轮）
1. **自建视频库**:不做外部推荐,用模板生成学习视频,减少 API 消耗
2. **视频单元 = 知识点,不是题**:讲解是技巧/方法/模板(知识点级),不是题解;一个知识点覆盖其下所有题,成本与题量无关、只与知识点数相关
3. **生成时机**:题目入库即后台入队(早于用户进入题目),做完题时视频已在库;失败降级到现有 B 站搜索卡
4. **例题**:视频自带通用经典例题(适配任意用户),与用户所做题目彻底解耦 → 视频题目无关,检索只看知识点
5. **差异化四轴**:讲解角度 12 个 / 叙事风格 6 / 画面模板 6 / 音色池随机组合(2000+ 观感);**热度分级铺格**(低 1 条 / 中 3 / 高 6+,use_count 驱动扩产)
6. **检索**:零 LLM——题干自带 knowledge_points + 学科计划考纲树层级;匹配分排行 + 用户自选
7. **冷启动**:先对学科计划题目批量暖库;存量题懒生成
8. **存储**:Supabase(起步够:上万行表毫无压力,音频 48kbps 单声道 1min≈0.4MB);预留 object-storage 抽象层,量大换 OSS+CDN;真正变量是播放 egress,起步不用操心
9. **模型**:脚本 qwen-turbo(0.3/0.6 元每百万,查当日报价;Batch 半价可夜间暖库);TTS 复用讯飞,可对比阿里 CosyVoice
10. **首落点**:DoQuestion 做题页(替换 B 站推荐为「本题知识点讲解」+ 相关排行自选)

### 架构
- 表:`video_library`(knowledge_key 主键轴 / subject / stage / angle / template_key / voice_key / script jsonb / audio_url / duration / status / anchor_examples / use_count / avg_rating / prompt_version / model / tts_engine)+ `question_video_links`(指纹↔视频 match_score 快照);Supabase Storage bucket `video-lib/{id}/audio.mp3`
- 队列:进程内 asyncio 队列挂 lifespan(复用 start_background_tuning 先例),不引入 celery/redis
- 幂等:(knowledge_key, angle) 唯一约束 + generating 占位,并发请求等复用
- 省 API 原则:按格生产/脚本与音轨解耦(换音色只重跑 TTS)/命中即绑定/Batch 半价暖库/懒生成+兜底
