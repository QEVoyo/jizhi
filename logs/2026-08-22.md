## 识图视觉模型切换：豆包 → DeepSeek（同日追加）

### 背景
DeepSeek 于 2026-08-21 上线官方视觉模型 **deepseek-v4-flash-vision-exp**（V4-Flash-Vision-Exp）：图文混合输入、支持 URL/base64/Files API、图片按 Token 计费不单收费（单张最多 384 tokens）、费率与 V4-Flash 一致。复用现有 `DEEPSEEK_API_KEY`，无需新 key。

| 文件 | 改动 |
|---|---|

| `backend/routers/chat.py` | `/chat/vision` 豆包 vision_stream → `call_llm_vision_stream`；删死代码 `doubao_stream_generator`、死 import json |

## 对话无响应排查（同日）

### 现象
用户首页发对话长时间无响应（无错误提示）。

### 排查
- 后端 8000 / 前端 5173 均在运行；DeepSeek chat API 直连 3.7s 正常
- 自签 JWT 端到端复测 `/chat/send`：200、首字节 2.5s、流式 2.2s 完整结束 ✅
- 后端 `--reload` 运行中，本会话改 5 个后端文件触发多次 worker 重启，期间在途请求会被杀 → 疑似用户发送时撞上重启窗口
- 前端 SSE 读取无任何超时：连接挂起时界面无限「调用 Agent」，不报错 → 与现象吻合

### 修复（防挂起）
- `api/chat.js` `sendChatMessage` 支持 AbortSignal
- `ChatArea.vue` 加 120s 流超时保护（AbortController），超时提示「响应超时，请重试」；finally 清理定时器

### 说明
- `check_content_safety` 是同步阻塞 LLM 调用（60s 超时），高峰期审核变慢会延迟首字节；审核异常时默认拒绝（fail-closed，设计如此）

## 智能体中心（概念讨论 + 硬编码预览，同日）

### 讨论结论（整体方案）
- **定位**：双视角（用户个人中心 + 管理后台全局统计）
- **范围**：核心 5 个智能体（对话/规划/生成/评估/小基），视觉、真题分析后续补
- **核心功能 = 磨合引擎**：不做模型微调，做「参数自适应」——用户行为数据（正确率/完成率/👍👎）→ 规则引擎自动微调 agent 参数（难度/风格/任务量）→ 下次调用实时拼装生效 → 中心展示磨合时间线
- **数据原则**：每个数字要么解释学习效果、要么导向动作；统计只是调整效果的证据
- **触点细化**：全触点地图 ~20 个（同一 agent 散落在聊天/资源库/做题页/真题/小基等）；后续工程第一步是"收编"——匿名 LLM 调用统一走 agents 包，参数/打点才能统一
