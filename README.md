## 项目简介

基智是面向备考场景的 AI 学习平台，核心由两条学习链路和一组辅助功能组成：

- **资源库链**：按考纲与掌握度生成题目，做题后即时批改并推送知识点讲解视频，作答沉淀为掌握度。
- **学科计划链**：诊断摸底后生成分阶段计划与每日任务，随完成情况动态调整任务量和难度。
- **评估中心**：两条链共用，形成「练习—评估—再计划」的闭环。
- **辅助功能**：小基 AI 助手（对话、识图、语音、视频分析）、个人画像、社区与学习成就、消息中心、管理后台。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Pinia + Element Plus + ECharts |
| 桌面端 | Rust + Tauri v2 + 系统 WebView2 |
| 后端 | FastAPI + httpx + asyncio |
| 数据 | Supabase（PostgreSQL + PostgREST + RLS） |
| AI | DeepSeek + 阿里云千问 + 讯飞语音识别 |
